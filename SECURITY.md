# Security

## Supported versions

Only the latest release on Hackage receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use
[private vulnerability reporting](https://github.com/jeremiepas/cypher-lite/security/advisories/new) on
GitHub. You should get an answer within a week. A fix is released before the details are made
public, and the report is credited unless you ask otherwise.
